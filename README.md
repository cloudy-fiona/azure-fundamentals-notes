# Azure Fundamentals Notes

This repository documents my Azure fundamentals learning as part of my
cloud and cloud security career roadmap.

The goal of this repo is not exam memorization, but to:
- Build a strong conceptual understanding of Azure services
- Compare Azure and AWS from a security and operations perspective
- Create a reference for future Azure Security (AZ-500) and cloud security work

## Topics Covered
- Core Azure services
- Compute, networking, and storage
- Identity and access management
- Basic security concepts
- Azure vs AWS comparisons
